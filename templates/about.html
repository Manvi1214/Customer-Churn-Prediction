Project Documentation

1. Problem Statement

In subscription-based services (SaaS, telecom, utility providers), customer attrition (churn) directly impacts recurring revenue and growth rates. Acquiring a new customer is significantly more expensive than retaining an existing one.

The goal of this project is to build an intelligent classifier that can analyze customer demographic profile details, subscription metrics, and service interaction signals to predict whether a customer will churn. This allows retention teams to target high-risk accounts with proactive engagement, maximizing lifetime value (LTV).

2. Dataset Attributes

The model is trained on a structured customer dataset comprising the following 10 customer features:

  • Age: Age of the customer (integer).
  • Gender: Female or Male (categorical).
  • Tenure: Total months the customer has been active (integer).
  • Usage Frequency: Number of times the customer used the service per month (integer).
  • Support Calls: Number of customer service calls made (integer).
  • Payment Delay: Number of days payment has been delayed past the due date (integer).
  • Subscription Type: Basic, Standard, or Premium tier (categorical).
  • Contract Length: Annual, Quarterly, or Monthly contract type (categorical).
  • Total Spend: Total monetary amount spent by the customer (numeric).
  • Last Interaction: Days since the customer's last interaction with the platform (integer).

3. Tech Stack

This project is built from scratch as a lightweight, production-grade Python web application utilizing the following technologies:

  • Frontend: Semantic HTML5, Vanilla CSS3 (custom responsive design system), and Vanilla JavaScript.
  • Backend: Python 3, Flask Web Framework, and Jinja2 templates.
  • Machine Learning: Scikit-learn (preprocessors & pipelines), Pandas (data manipulation), NumPy (array operations), and Joblib (object serialization).
  • Visualization: Matplotlib and Seaborn (generating model evaluation plots).

4. Machine Learning Algorithm

We implemented a Random Forest Classifier, an ensemble machine learning method that trains multiple decision trees and averages their predictions (bagging).

The preprocessing pipeline encodes categorical columns using `OneHotEncoder`, standardizes continuous numeric columns using `StandardScaler`, and imputes any missing values. The classifier uses balanced class weights and a regulated tree depth (`max_depth=12`) to prevent overfitting.

5. Workflow Pipeline

The system operates in two distinct scripts to separate training from application runtime:

  1. Training (`train_model.py`): Cleans raw data, constructs the preprocessing pipeline, fits features, trains the Random Forest classifier, generates static evaluation charts, and saves serialized model artifacts.
  2. Application (`app.py` & `predict.py`): Launches a local web server, exposes input endpoints, decodes user form entries, loads the pre-trained preprocessing pipeline and classifier, runs predictions in real-time, and renders results.

6. Future Scope

To scale this application for enterprise deployment, the following enhancements are proposed:

  • Database Integration: Store user input submissions and actual churn feedback dynamically in a relational database (e.g., Cloud SQL or PostgreSQL) to facilitate model retraining.
  • SHAP Explanations: Implement SHAP (SHapley Additive exPlanations) to explain individual predictions on a deeper mathematical level.
  • AutoML Pipeline: Automate hyperparameter tuning and model retraining on a scheduler using tools like Airflow and MLflow.
